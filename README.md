# 🛡️ SOC Home Lab & SIEM Investigation

## 📌 Project Overview

Built a virtual cybersecurity lab using VirtualBox to simulate a Security Operations Center (SOC) environment.

The project focuses on security monitoring, SIEM investigations, log analysis and network security.

## 🛠️ Tools & Technologies

- VirtualBox
- Kali Linux
- Splunk SIEM
- Wireshark
- Nmap
- Snort IDS

## 🔍 Practical Activities

### 1. SIEM Monitoring & Investigation
- Worked with security logs using Splunk.
- Performed log searches and filtering.
- Analyzed security events.
- Investigated suspicious activities.

### 2. Network Traffic Analysis
- Captured and analyzed network packets using Wireshark.
- Examined TCP/IP communication.
- Analyzed DNS and HTTP traffic.

### 3. Network Scanning
- Performed network scanning using Nmap.
- Identified open ports and services.
- Explored network reconnaissance techniques.

### 4. Intrusion Detection
- Explored Snort IDS.
- Studied intrusion detection concepts.
- Learned how suspicious network traffic can generate alerts.

## 🔄 SOC Investigation Workflow

1. Security Event Monitoring
2. Alert Identification
3. Initial Alert Triage
4. Log Analysis
5. Network Traffic Investigation
6. Incident Documentation
7. Recommended Response
